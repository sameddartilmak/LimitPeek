Sorular.Questions. Kısa cevaplar.Short answers.

Yüzdeyi nereden alıyor?Where does the percentage come from?

Aracın kendisinden. Claude Code’un durum satırı ve Codex’in oturum kayıtları sunucunun hesapladığı oranı taşır. Antigravity’nin 5 saatlik oranı IDE’nin yerel deposundan, belgelenmemiş bir biçimden okunur. Yerel token sayısından yüzde üretilmez.From the tool itself. Claude Code’s status line and Codex’s session logs carry the server-computed figure. Antigravity’s 5-hour figure is read from the IDE’s local store, an undocumented format. No percentage is made from local token counts.

Maliyet bir fatura mı?Is the cost a bill?

Hayır. Aboneliğindeki kullanımın yayımlanan API fiyatlarıyla ne tutacağının tahminidir. Kaydedilmeyen ayrıntılar hep aynı yöne kaymaz: Codex’in kaydetmediği önbellek yazmaları yüksek taraftan sayılır; süresi kaydedilmemiş Claude Code önbellek yazmaları ve Codex’te istenen hızlı katman ise düşük taraftan. Fiyatlanamayan kullanım toplama girmez.No. It is an estimate of what your subscription usage would cost at published API prices. Missing details do not all lean the same way: cache writes Codex does not record are counted on the high side, while Claude Code cache writes with no recorded duration and a requested Codex fast tier are counted on the low side. Usage that cannot be priced stays out of the total.

İnternete bağlanıyor mu?Does it go online?

Telemetri, çökme raporu ya da güncelleme denetimi hiç yok; uygulama kendiliğinden ağa hiç çıkmaz. Kendi sürecinde DNS-over-HTTPS’i kapalıya sabitler ve sistem vekil sunucusunu kullanmaz. Antigravity satırında Bağla’ya bastığında CLI kurulu değilse, onayınla antigravity.google’dan bir kez indirilir.There is no telemetry, crash reporting or update check at all, and the app makes no network requests of its own. It pins DNS-over-HTTPS off inside its own process and does not use a system proxy. And if you press Connect on the Antigravity row with the CLI missing, it is downloaded once from antigravity.google, with your consent.

Neyi okuyor?What does it read?

Araçların yerel kayıtlarından yalnızca ölçüm alanlarını alır: yüzdeler, sıfırlanma zamanları, token sayıları, model adları. Sohbet metni saklanmaz ve günlüğe yazılmaz; Claude’un kimlik dosyası ve Codex’in auth.json’ı hiç açılmaz.From the tools’ local records it takes only measurement fields: percentages, reset times, token counts, model names. Chat text is never stored or logged; Claude’s credentials file and Codex’s auth.json are never opened.

Kendini güncelliyor mu?Does it update itself?

Hayır, otomatik güncelleme yok. Yeni bir sürümü GitHub Releases sayfasından kendin kurarsın.No, there is no automatic update. You install a new version yourself from the GitHub Releases page.
