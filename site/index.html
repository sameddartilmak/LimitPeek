    Güvenilir bir limit yoksa ne yüzde ne çubuk çizer; “bildirilmiyor” yazar. Yerel token sayısından yüzde üretmez.Without a trustworthy limit it draws no percentage and no bar; it says “not reported”. It never turns local token counts into a percentage.

  2. Veri bilgisayarında kalırData stays on your PC

    Ölçüm alanlarını araçların yerel dosyalarından alır. Anahtar kaydetmezsen kendiliğinden ağa çıkmaz; kayıtlı Copilot anahtarı varsa yalnızca api.github.com’a, en sık 15 dakikada bir — ve bu adın çözümü Windows’un kendi DNS ayarlarıyla yapılır. Sistem vekil sunucusunu kullanmaz: vekil gerektiren bir ağda bu tek sayı gösterilemez, geri kalan her şey yerelden okunmaya devam eder. Antigravity CLI ise onayınla bir kez indirilir.It takes measurement fields from the tools’ local files. Unless you store a key it makes no network requests of its own; with a Copilot key stored it requests api.github.com only, at most once every 15 minutes — and resolving that name uses your Windows DNS settings. The Antigravity CLI is downloaded once, with your consent.

Sorular.Questions. Kısa cevaplar.Short answers.

Yüzdeyi nereden alıyor?Where does the percentage come from?

Aracın kendisinden. Claude Code’un durum satırı ve Codex’in oturum kayıtları sunucunun hesapladığı oranı taşır. Antigravity’nin 5 saatlik oranı IDE’nin yerel deposundan, belgelenmemiş bir biçimden okunur. Yerel token sayısından yüzde üretilmez.From the tool itself. Claude Code’s status line and Codex’s session logs carry the server-computed figure. Antigravity’s 5-hour figure is read from the IDE’s local store, an undocumented format. No percentage is made from local token counts.

Maliyet bir fatura mı?Is the cost a bill?

Hayır. Aboneliğindeki kullanımın yayımlanan API fiyatlarıyla ne tutacağının tahminidir. Kaydedilmeyen ayrıntılar hep aynı yöne kaymaz: Codex’in kaydetmediği önbellek yazmaları yüksek taraftan sayılır; süresi kaydedilmemiş Claude Code önbellek yazmaları ve Codex’te istenen hızlı katman ise düşük taraftan. Fiyatlanamayan kullanım toplama girmez.No. It is an estimate of what your subscription usage would cost at published API prices. Missing details do not all lean the same way: cache writes Codex does not record are counted on the high side, while Claude Code cache writes with no recorded duration and a requested Codex fast tier are counted on the low side. Usage that cannot be priced stays out of the total.

İnternete bağlanıyor mu?Does it go online?

Telemetri, çökme raporu ya da güncelleme denetimi hiç yok. Anahtar kaydetmezsen uygulama kendiliğinden ağa çıkmaz. İsteğe bağlı Copilot API anahtarı eklersen yalnızca api.github.com’a, en sık 15 dakikada bir ve yalnızca o satır açıkken gider; bu ayki AI kredilerini okur. Bu adın çözümü Windows’un kendi DNS ayarlarıyla yapılır — uygulama kendi sürecinde DNS-over-HTTPS’i kapalıya sabitler. Sistem vekil sunucusunu da kullanmaz, yani vekil gerektiren bir ağda bu tek sayı gösterilemez; satırdaki diğer her şey yerelden okunmaya devam eder. Antigravity satırında Bağla’ya bastığında CLI kurulu değilse, onayınla antigravity.google’dan bir kez indirilir.There is no telemetry, crash reporting or update check at all. Unless you store a key, the app makes no network requests of its own. If you add the optional Copilot API key it requests api.github.com only, at most once every 15 minutes and only while that row is enabled, to read this month’s AI credits. Resolving that name uses your Windows DNS settings — the app pins DNS-over-HTTPS off inside its own process. It does not use a system proxy either, so on a network that requires one that single figure is unavailable; everything else on the row is still read locally. And if you press Connect on the Antigravity row with the CLI missing, it is downloaded once from antigravity.google, with your consent.

Copilot anahtarı nerede duruyor?Where does the Copilot key live?

Anahtar bu bilgisayarda, bu Windows kullanıcısına özel olarak şifrelenip saklanır; bu, diğer kullanıcı hesaplarına ve dosyanın kopyalanmasına karşı korur, bu kullanıcı olarak çalışan programlara karşı korumaz. İstediğin zaman Ayarlar’dan kaldırabilirsin; bu yalnızca bu bilgisayardaki kopyayı siler, anahtarı ayrıca GitHub’da iptal etmen gerekir. Yazdığın değer bir daha hiçbir ekranda gösterilmez ve bilgisayardan yalnızca o tek isteğin Authorization başlığında çıkar.The key is stored on this computer, encrypted for this Windows user; that protects it from other user accounts and from copies of the file, but not from programs running as this user. You can remove it in Settings at any time; that deletes only the copy on this computer, so you also need to revoke the key at GitHub. What you typed is never shown on any screen again, and it leaves the PC only in the Authorization header of that one request.

Neyi okuyor?What does it read?

Araçların yerel kayıtlarından yalnızca ölçüm alanlarını alır: yüzdeler, sıfırlanma zamanları, token sayıları, model adları. Sohbet metni saklanmaz ve günlüğe yazılmaz; Claude’un kimlik dosyası ve Codex’in auth.json’ı hiç açılmaz. Copilot anahtarı verirsen gelen yanıttan yalnızca kredi sayıları tutulur.From the tools’ local records it takes only measurement fields: percentages, reset times, token counts, model names. Chat text is never stored or logged; Claude’s credentials file and Codex’s auth.json are never opened. With a Copilot key, only the credit counts are kept from the reply.

Kendini güncelliyor mu?Does it update itself?

Hayır, otomatik güncelleme yok. Yeni bir sürümü GitHub Releases sayfasından kendin kurarsın.No, there is no automatic update. You install a new version yourself from the GitHub Releases page.
